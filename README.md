# Travel Booking Platform

A console-based Travel Booking Platform developed using Java and MySQL.

## Features

- User Registration
- User Login
- View Travel Destinations
- Book a Trip
- Payment Processing
- View My Bookings
- MySQL Database Integration

## Technologies Used

- Java 17
- MySQL 8.0
- JDBC
- VS Code

## Database

Database Name:

travel_booking

Main Tables:

- users
- destinations
- bookings
- payments
